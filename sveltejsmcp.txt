# SvelteJS MCP Integration Guide
# Context7 Documentation & Research Prompts for Legal AI Web Development

## 🚀 SYSTEM OVERVIEW

Your Legal AI platform integrates Context7 MCP (Model Context Protocol) to provide enhanced documentation and intelligent code suggestions for modern web development with:

- **SvelteKit 2** with **Svelte 5 runes** ($state, $props, $derived, $effect)
- **Bits UI v2** headless components
- **Melt UI v0.39.0** builders and actions
- **XState v5** state machines
- **TypeScript** strict mode
- **Drizzle ORM** with PostgreSQL + pgvector
- **MinIO** file storage
- **Ollama** local AI processing

## 📚 CONTEXT7 MCP ENDPOINTS

### Available Documentation APIs

```bash
# Base endpoint
POST http://localhost:5173/api/mcp/context72/get-library-docs

# Content-Type: application/json
{
  "context7CompatibleLibraryID": "/sveltejs/svelte",
  "topic": "runes",
  "tokens": 15000,
  "format": "typescript"
}
```

### Supported Libraries

| Library ID | Description | Best Topics |
|------------|-------------|-------------|
| `/sveltejs/svelte` | Svelte 5 with runes | runes, props, effects, migration |
| `/bits-ui/bits-ui` | Headless UI components | dialog, button, select, forms |
| `/melt-ui/svelte` | UI builders for Svelte | button, dialog, tooltip, builders |
| `/statelyai/xstate` | State machines | machine, context, actions, guards |
| `/drizzle-team/drizzle-orm` | TypeScript ORM | queries, relations, migrations |
| `/microsoft/typescript` | TypeScript language | types, interfaces, generics |
