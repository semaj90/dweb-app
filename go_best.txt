#### 3. Service Health Monitoring
**Create**: `go-microservice/scripts/health-check.ps1`
```powershell
# Health check script for all services
$services = @(
    @{Name="Enhanced RAG"; Url="http://localhost:8094/api/health"},
    @{Name="Upload Service"; Url="http://localhost:8093/health"},
    @{Name="Vector Service"; Url="http://localhost:8095/health"}
)

foreach ($service in $services) {
    try {
        $response = Invoke-WebRequest -Uri $service.Url -TimeoutSec 5
        Write-Host "✅ $($service.Name): Healthy" -ForegroundColor Green
    } catch {
        Write-Host "❌ $($service.Name): Unhealthy" -ForegroundColor Red
    }
}
```
