## RAG User Journey Implementation (8 Steps)

### Step 1: User Uploads a Document (Frontend & Backend API)
**Flow**: User drags 500-page PDF → SvelteKit frontend → POST /api/documents/upload
**Status**: Implemented via SvelteKit server routes + Go upload service (port 8093)

### Step 2: File Storage & Database Record
**Flow**: Stream to MinIO S3 → Create PostgreSQL record with metadata
**Status**: MinIO integration + PostgreSQL schema ready

### Step 3: Job Queue Publication
**Flow**: Publish to RabbitMQ doc_processing_queue → Return 202 Accepted
**Status**: RabbitMQ messaging system implemented

### Step 4: Background Worker Processing
**Flow**: Worker consumes queue message → Downloads from S3
**Status**: Go worker services operational

### Step 5: OCR & Text Extraction
**Flow**: Tesseract OCR → Raw text extraction
**Status**: Tesseract integration available

### Step 6: Chunking & Embedding
**Flow**: LangChain RecursiveCharacterTextSplitter → Ollama nomic-embed API calls
**Status**: LangChain.js integration + Ollama endpoints ready

### Step 7: Vector Storage
**Flow**: Insert chunks + embeddings into PostgreSQL pgvector table
**Status**: pgvector extension installed, schema configured

### Step 8: Summarization (Map-Reduce)
**Flow**: LangChain Map-Reduce chain → Ollama Gemma3-legal → Final summary
**Status**: LangChain summarization chains + Ollama Gemma3 model ready
