🔀 Integration Examples

Both implementations are compatible with neo4j-driver JavaScript patterns:

// Server-side usage const serverGraph = { async query(cypher) { const response = await fetch('http://localhost:7474/api/graph/query', { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ query: cypher }) }); return response.json(); } }; // WASM usage (when compiled) const wasmGraph = { query(cypher) { return wasmExecuteCypher(cypher); }, createNode(id, label, properties) { return wasmCreateNode(id, label, properties); } }; // Unified interface const graph = useWasm ? wasmGraph : serverGraph; const results = await graph.query('MATCH (n:Case) RETURN n');
