# Legal AI Platform - Component Library

Welcome to the **Legal AI Platform** component library! This Storybook contains all the UI components, business logic components, and specialized legal interface elements built with **SvelteKit 2** and **Svelte 5**.

## 🏗️ Architecture

Our component architecture is built around:

- **SvelteKit 2** with **Svelte 5** features (runes, snippets)
- **TypeScript** for type safety
- **Melt UI** for headless components
- **Bits UI** for advanced primitives
- **Tailwind CSS** for styling
- **UnoCSS** for performance

## 📚 Component Categories

### Core UI Components
Base building blocks including buttons, cards, inputs, and layout components.

### Business Logic Components
Specialized components for legal case management, AI chat interfaces, and document processing.

### Legal Specialized Components
Purpose-built components for evidence handling, legal workflow management, and court document processing.

### YoRHa Theme Components
Futuristic detective-style interface components inspired by the NieR series.

## 🎨 Design System

Our design system follows legal industry standards while incorporating modern UI patterns:

- **Professional** color palette suitable for legal work
- **Accessible** components meeting WCAG guidelines  
- **Responsive** design for desktop, tablet, and mobile
- **Dark mode** support for extended usage

## 🚀 Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm run storybook
```

### Testing

Components include built-in accessibility testing and interaction testing through Storybook.

## 🔍 Key Features

- **AI-Powered Components**: Chat interfaces with legal AI models
- **Vector Search**: Semantic document search capabilities  
- **Real-time Updates**: Live case status and evidence tracking
- **Multi-Protocol APIs**: REST, gRPC, QUIC, and WebSocket support
- **GPU Acceleration**: WebGPU and CUDA integration for performance
