### SvelteKit Routing Convention

**Standard Pattern:** `src/routes/api/path/+server.ts`
- Automatically serves JSON via `json()` helper
- Content-Type: application/json header set automatically
- No manual extensions needed

### When .json Extensions ARE Needed

**Scenario 1: Multiple Format Support**
```
src/routes/api/users/+page.server.ts  (HTML)
src/routes/api/users.json/+server.ts  (JSON only)
```

**Scenario 2: Explicit Content-Type Routing**
```
src/routes/api/data.json/+server.ts   (Force JSON)
src/routes/api/data.xml/+server.ts    (Force XML)
```

**Scenario 3: Legacy API Compatibility**
```
src/routes/api/v1/posts.json/+server.ts  (Match existing API)
```
