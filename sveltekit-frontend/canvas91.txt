## 🏗️ **ARCHITECTURE OVERVIEW**

### **Data Flow:**
```
User Input → Button Handler → State Update → Database Save
     ↓            ↓              ↓             ↓
Analytics → Format Change → Queue Message → Redis Cache
     ↓            ↓              ↓             ↓  
UI Update → Canvas Render → Remote Sync → Loki.js Store
```

### **Multi-Tier Caching:**
```
Level 1: Loki.js (< 1ms access, in-memory)
Level 2: Redis (< 50ms access, distributed) 
Level 3: NES Memory (< 100ms access, cold storage)
```
