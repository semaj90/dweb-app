🌐 SERVICE ARCHITECTURE & FEATURES
===============================================================================

## QUIC Gateway (quic-gateway.go)
**Purpose**: HTTP/3 gateway proxy to SvelteKit frontend
**Key Features**:
- Self-signed TLS certificate generation for development
- HTTP/3 primary with HTTP/2 fallback support  
- Configurable backend URL (defaults to SvelteKit on port 5173)
- Health check endpoint: /health
- Proxy headers: X-Forwarded-Proto, X-Forwarded-For, Alt-Svc
- Environment configuration: QUIC_GATEWAY_PORT, BACKEND_URL

## QUIC Vector Proxy (quic-vector-proxy.go)  
**Purpose**: High-performance vector operations with intelligent caching
**Key Features**:
- Multi-backend routing (Qdrant vector DB + PostgreSQL pgvector)
- Intelligent caching system with TTL and hit tracking
- Vector search API: POST /api/vector/search
- Cache management with configurable TTL and size limits
- Backend health monitoring and failover
- Environment configuration: QDRANT_URL, PGVECTOR_URL, VECTOR_CACHE_TTL

**API Endpoints**:
- `/health` - Service health and backend status
- `/api/vector/search` - Vector similarity search with caching
- `/qdrant/*` - Direct Qdrant proxy endpoints

## QUIC AI Stream (quic-ai-stream.go)
**Purpose**: Real-time AI streaming with session management  
**Key Features**:
- WebSocket streaming endpoint: wss://localhost:8447/ws/stream
- HTTP streaming fallback: POST /api/stream (Server-Sent Events)
- Session management with context tracking
- Multi-backend AI integration (Ollama + Enhanced RAG)
- Real-time streaming chunks with metadata
- Context-aware request routing (RAG vs direct Ollama)

**API Endpoints**:
- `/ws/stream` - WebSocket streaming interface
- `/api/stream` - HTTP streaming (SSE) interface  
- `/api/sessions` - Session management and monitoring
- `/health` - Service and backend health status

## RAG QUIC Proxy (rag-quic-proxy.exe)
**Purpose**: Enhanced RAG service proxy with advanced caching
**Key Features**:
- Edge caching with ETag revalidation for GET requests
- JSON response optimization and compression
- Prometheus metrics integration (cache hits, response times)
- Conditional GET support with 304 Not Modified responses
- Request body caching for POST operations
- Environment configuration: RAG_BACKEND_URL, QUIC_EDGE_CACHE_TTL
