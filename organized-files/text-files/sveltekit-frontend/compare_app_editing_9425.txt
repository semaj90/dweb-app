Use a dedicated embedding model (nomic-embed-text, bge-small, or e5) — don’t use Gemma/generative model to build vectors.

llama.cpp (GGUF) works for embeddings if your model supports embedding mode (GGUF embedder models). For generator models, use them for generation only.

Prefer native llama.cpp on server (Node + node-llama-cpp or a local Python/Go worker) over browser WASM for heavy embeddings & generation. WASM is possible but less efficient and limited by browser sandbox/threads.

Keep a uniform internal API (gRPC proto + REST fallback) that all services call for embeddings/ingest/search. This decouples model runtime from callers.

Use RabbitMQ to queue ingest/embedding jobs; GPU workers consume them.

Store canonical documents & chunk metadata in Postgres (Drizzle), store embeddings in pgvector column and optionally mirror into Qdrant for scale.

2 — Ingest pipeline (concrete flow)

User uploads file → stored to MinIO (S3-compatible).

API publishes document.uploaded job to RabbitMQ with { documentId, minioUri, uploaderId }.

Ingest worker downloads file from MinIO (to local disk or tmp), extracts text:

Preferred for your environment (RTX 3060 Ti):

Node options:

5 — Similarity search (Drizzle raw SQL example)
import { sql } from "drizzle-orm";

export async function searchChunksByEmbedding(queryVec: number[], limit = 10) {
  const rows = await db.execute(
    sql`SELECT id, document_id, text, vector <-> ${sql.param(queryVec)} AS distance
        FROM document_chunks
        WHERE vector IS NOT NULL
        ORDER BY vector <-> ${sql.param(queryVec)}
        LIMIT ${sql.param(limit)}`
  );
  return rows;
}

// worker/ingest-embedder.ts (Node)
import amqp from 'amqplib';
import fetch from 'node-fetch';
import { Client as LlamaClient } from 'node-llama-cpp'; // hypothetical
import { db } from '../src/lib/server/db';
import { document_chunks } from '../src/lib/server/db/schema-postgres';
import { sql } from 'drizzle-orm';

const AMQP = process.env.AMQP_URL || 'amqp://localhost';
const OLLAMA = process.env.OLLAMA_URL || 'http://127.0.0.1:11434/api/embeddings';
const USE_LLAMA_CPP = true;

let llm: any = null;
async function initLlama() {
  if (!USE_LLAMA_CPP) return;
  llm = new LlamaClient({ model: '/models/bge-small.gguf', embedding: true });
}

async function embedText(text: string) {
  if (USE_LLAMA_CPP && llm) {
    return await llm.embed(text); // returns number[]
  }
  // fallback to Ollama
  const res = await fetch(OLLAMA, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ model: 'nomic-embed-text', input: text })
  });
  const j = await res.json();
  return j.embedding;
}

async function main() {
  await initLlama();
  const conn = await amqp.connect(AMQP);
  const ch = await conn.createChannel();
  await ch.assertQueue('q.document.ingest', { durable: true });
  ch.consume('q.document.ingest', async (msg) => {
    if (!msg) return;
    const job = JSON.parse(msg.content.toString());
    try {
      // download file from MinIO (use aws-sdk S3)
      // extract text, chunk into passages
      // For demo assume chunks[] = [{ text }]
      for (const chunk of chunks) {
        const vec = await embedText(chunk.text);
        // insert chunk and vector into DB via Drizzle or raw SQL
        await db.insert(document_chunks).values({
          document_id: job.documentId,
          chunk_index: chunk.index,
          text: chunk.text,
          tokens: chunk.tokens,
          vector: vec,
          metadata: {}
        });
      }
      ch.ack(msg);
    } catch (err) {
      console.error('ingest failed', err);
      ch.nack(msg, false, false); // DLQ
    }
  }, { noAck: false });
}

main().catch(console.error);
